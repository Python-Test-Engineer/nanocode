Nanocode, one picture at a time

Each chapter of Nanocode, explained turns on one diagram. Here those diagrams move: packets follow the arrows, sessions fill, gates open and refuse, and subagents recurse. The original ASCII is preserved under every animation, because the ASCII is still the source of truth.

Chapter 01The event loop (there is no AI yet)

A packet walks the loop: ask, handle, answer, repeat. The /q branch leaves the loop through AgentStop.

The animation is the diagram in motion. The original ASCII is preserved below.
Original ASCII picture — The idea in one picture 
        ┌──────────────────────────────────────────────┐
        │                 main() loop                  │
        │                                              │
        ▼                                              │
  ui.ask()  ──►  Agent.handle_input(text)  ──►  ui.answer(output)
   "❯ "              │                                   │
                     │ "/q" ?                            │
                     ├── yes ──► raise AgentStop ─────────┼──► exit
                     └── no  ──► return a string ─────────┘

Chapter 13Sound (the agent's hooks you can hear)

The hook bus is a seam. Register a sound per event, and the loop becomes audible without changing the loop.

The animation is the diagram in motion. The original ASCII is preserved below.
Original ASCII picture — Why sound at all — the four events 
session_start ─► ♪ tada         the session is up
turn_start    ─► ♪ ding         your turn is being handled
tool_call     ─► ♪ chimes       something is being read/written/run right now
turn_end      ─► ♪ notify       the answer is ready

Chapter 14A sandbox for ACT mode

Every write passes the guard and the sandbox. Allowed writes open the file; refused writes return an error string.

The animation is the diagram in motion. The original ASCII is preserved below.
Original ASCII picture — The idea in one picture 
                    ACT mode only
   ┌──────────────────────────────────────────────────────────────┐
   │  model: write_file("C:\\Windows\\Temp\\proof.txt", ...)      │
   └───────────────────────────────┬──────────────────────────────┘
                                   ▼
                         tools.WriteFile.execute
                                   │
                    context.guard(path, "write_file")
                                   ▼
                         sandbox.Sandbox.check
                     resolve ─► deny? ─► root prefix test
                                   │
              ┌────────────────────┴─────────────────────┐
              ▼ allowed                                  ▼ refused
        open(path, "w")                    hooks.emit("sandbox_denied")
        "Successfully wrote …"                        │
                                          ┌───────────┴────────────┐
                                          ▼                        ▼
                                   ui.forbidden            sounds.alarm
                                 ⛔ FORBIDDEN …        ♪ Windows Exclamation
                                          │
                                          ▼
                        tool returns "Error: FORBIDDEN … "
                        (the model reads it; the loop continues)

Chapter 15Subagents, and four ways to arrange them

A tool asks the parent to spawn. The child runs the same loop, one stack frame deeper, and returns one string.

The animation is the diagram in motion. The original ASCII is preserved below.
Original ASCII picture — The idea in one picture 
   parent._agentic_loop()                         one Python process
   │
   ├─ thought: run_subagent(task)
   │     │
   │     └─ tools.RunSubagent.execute(context, task)
   │           │
   │           └─ context.spawn(task)             ← the tool only ASKS
   │                 │
   │                 └─ Agent._spawn_subagent(task)
   │                       │  fresh brain / conversation / tools
   │                       │  fresh sandbox / hooks
   │                       ▼
   │                    child._agentic_loop()     ← the same method, recursing
   │                       ├─ thought: read_file(...)   ┐
   │                       ├─ thought: search_codebase  ├ the child's own turn:
   │                       └─ answer: "…"               ┘ its own context, its own
   │                                                        tool results, its own
   │                       ▲                                iteration budget
   │                       │  one string
   │     ◄─────────────────┘
   │
   ├─ tool_result: "…"        ← the parent's conversation grew by ONE message
   └─ thought: the merged answer
